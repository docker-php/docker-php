---
title: "Docker PHP"
description: "Use the Docker Engine API from PHP."
---

Docker PHP is a PHP client for the Docker Engine API. It provides generated
endpoint methods and models, connection handling, and decoded log and command
output streams.

<Note>
These docs cover the Docker PHP 3.0 client and Docker API package 7.1.45.0.
</Note>

The first restored release targets Docker Engine API v1.45. The PHP namespaces
remain `Docker` and `Docker\API`, including for applications migrating from
Beluga.
