## Requirements

- PHP 8.1 or later, with the `mbstring` extension.
- [Composer](https://getcomposer.org/).
- Access to a Docker daemon that accepts API v1.45 requests.

## Stable installation

```bash
composer require "docker-php/docker-php:^3.0"
```

Composer installs the matching `docker-php/docker-php-api` dependency. If your
application requires the API package directly, keep its constraint within one
[API line](/api-versions).

## Test the development version

For a disposable test application, explicitly allow both development packages:

```bash
composer require "docker-php/docker-php:3.0.x-dev" "docker-php/docker-php-api:7.1.45.x-dev" --with-all-dependencies
```

Do not use these moving development versions for an unattended production
upgrade. Commit your application's `composer.lock` after testing.

If you already use Docker PHP or Beluga, follow the [migration guide](/migration)
instead of installing both package families together.
